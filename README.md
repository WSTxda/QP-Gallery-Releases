## Features

#### Material 3 style redesign

- Stylize default Holo/Material themes with Material 3 style components, reorganized settings, and Material Symbols icons.
- Support Monet dynamic colors, custom palettes, translucent, and a pitch-black AMOLED theme.
- Support themed and Adaptive Icons, animated splash screen, tall aspect ratios, display cutouts, and foldable screens.

#### Privacy and debloat

- Remove Cheetah Mobile trackers, Umeng analytics, background telemetry, and ads.
- Remove broken cloud integrations and unnecessary network permissions.
- Clean up obfuscated code and redundant resources to reduce apk size and prevent Play Protect or VirusTotal warnings.

#### Android compatibility and storage

- Update FileProvider, Storage Access Framework (SAF), and storage permissions for recent Android versions.
- Fix external SD card mounting, OTG file operations, and media corruption during file moves, copy or edits.
- Fix gesture navigation conflicts, Android 13+ notification media opening, MIUI dark mode glitches, GIF flickering, and crashes.

#### Media and tools

- Optimize thumbnail caching, album loading, video player buffering, and EXIF aperture reading.
- Support image format conversion in the built-in editor and selectable text in the media details dialog.
- Restore local Wi-Fi file transfers with Nearby Devices permission support.
- Add an in-app update checker in settings.

## Requirements

> [!WARNING]
> **32-bit Support Required:** This app relies on legacy 32-bit libraries (`armeabi-v7a`). Newer **64-bit-only devices** launched with recent Android versions (Android 14/17+) will **not** be able to install or run this mod. Please check your device's architecture before proceeding.
